# AMON AI — Project Documentation

AMON AI هو نظام ذكاء اصطناعي مركزي يعمل حاليًا على Cloudflare Workers مع واجهة ويب داخل public/.

## المبدأ
AMON ليس نموذجًا واحدًا. الطبقات الرئيسية هي:
- فهم الطلب والسياق.
- إدارة الأهداف والمهام.
- التفكير متعدد المسارات والتحقق.
- الذاكرة وقاعدة المعرفة عند توفر التخزين.
- موجّه الأدوات.
- مقارنة النماذج والمزوّدين.
- البحث متعدد المصادر عند توفر الاتصالات.
- الأمان والجلسات والتعافي والقياس.
- واجهة المستخدم.

## قاعدة العمل
لا نستخدم كلمة مكتمل إلا عندما يوجد في الكود، وتمت مراجعته، واختباره، والتحقق من تكامله، والتحقق من النشر الفعلي عند الحاجة.

## الهيكل الحالي
- worker.js — runtime وAPI وطبقات AMON الخلفية الحالية.
- public/index.html — الواجهة الأمامية الحالية.
- public/amon-supabase.js — طبقة الحساب والحفظ عبر Supabase.
- amon-owner.js — واجهة أدوات المالك.
- wrangler.toml — إعداد Cloudflare Worker وAssets.
- package.json — أوامر المشروع والحزم.

## ملاحظات أمنية
- المستودع الحالي ظاهر كـ Public؛ يجب مراجعة قرار الخصوصية قبل أي إطلاق حقيقي.
- لم يظهر في المستودع أي مفتاح API سري وفق فحص الأنماط الشائعة، والأسرار يجب أن تبقى في Cloudflare Secrets.
- دعم الذاكرة وقاعدة المعرفة موجود في الكود، لكن wrangler.toml الحالي لا يثبت وجود KV bindings لهما.
