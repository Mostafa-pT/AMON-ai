## قاعدة سياق الإنترنت
بلد المستخدم هو السياق الافتراضي فقط. يستطيع أي مستخدم اختيار بلد آخر أو عدة بلدان أو البحث عالميًا. يحدد السؤال والنطاق الجغرافي المطلوب مسار البحث؛ لا يجوز حصر البحث تلقائيًا في بلد المستخدم.
