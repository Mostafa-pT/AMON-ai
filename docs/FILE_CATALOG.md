## البنية المستهدفة — ليست وحدات تشغيلية منشأة بعد
src/worker.js — مدخل Cloudflare خفيف.
src/core/ — هوية AMON وفهم الطلب والسياق وتخطيط المهام.
src/reasoning/ — التفكير متعدد المسارات والمجلس والتحقق.
src/memory/ — سياسة الذاكرة ومخزنها.
src/knowledge/ — قاعدة المعرفة والاسترجاع.
src/tools/ — سجل الأدوات والموجه وتحليل الملفات.
src/providers/ — كتالوج المزوّدين، adapters، فحص الاتصال، والتبديل الاحتياطي.
src/research/ — محولات البحث وسجل المصادر وذكاء الإنترنت العالمي وملفات الدول والأدلة.
src/security/ — الجلسات والحدود والأسرار وصلاحيات المالك.
src/recovery/ — التعافي من أخطاء النماذج.
src/diagnostics/ — الاختبارات الذاتية والتدقيق والقياسات.
src/routes/ — معالجات API.
public/css/ — رموز الألوان والثيمات والتخطيط والمكونات.
public/js/ — التطبيق والمحادثة والإعدادات والملفات والمالك.
public/assets/ — الشعار والوسائط.
tests/unit/ وtests/integration/ وtests/fixtures/ — اختبارات الوحدة والتكامل وبيانات الاختبار.
docs/ — دليل المشروع، الفهرس، سجل الميزات، الخطة، وإجراءات النشر.

## معيار التسمية
- ملفات JS وCSS والوثائق بأسماء وصفية صغيرة kebab-case مثل request-understanding.js وtheme-tokens.css.
- تجنب أسماء عامة مثل new.js وfinal2.js وhelper.js.
- لا تغيّر مسارات ملفات التشغيل الحالية قبل تعديل imports وwrangler.toml وأوامر البناء واختبار النشر معًا.
- لا تنشئ ملفات فارغة على أنها ميزات مكتملة؛ البنية أعلاه خريطة مستقبلية.
